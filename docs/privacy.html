Privacy Policy

Last updated: 23 October 2026

Fricomind is a tool operated by its owner to publish educational videos to the owner's own YouTube channel. It is not offered to the public and has no user accounts.

Data we access

When the owner signs in with Google, the tool requests permission to upload videos to the owner's own YouTube channel. It uses this permission only to upload videos and set their title, description and tags.

Data we store

The only data kept is an access token that lets the tool upload to the owner's channel. It is stored as an encrypted secret in the owner's private GitHub account. We do not collect, sell, share or disclose any personal data of viewers or other people.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
